# Feature: Final Summary Generation
**Owner:** Backend | **Module:** Agent Conversation

## Goal
Once all needed steps are complete, return a clear, human-readable
summary of what was done.

## Scope
- The agent's final text response (generated by Gemini via the Agents
  SDK) summarizing: what was looked up, what was decided, what actions
  were taken (or are pending approval).
- Saved as the assistant's message in the conversation history.
